Mình làm gì

Website & landing page

Giao diện nhanh, hiển thị tốt trên điện thoại, nối với form hoặc cơ sở dữ liệu khi cần.

Tự động hóa bằng AI & code

Script, tích hợp API, extension trình duyệt, xử lý biểu mẫu và tài liệu để bớt thao tác thủ công.

Hệ thống phía sau

API, PostgreSQL, Docker, kiến trúc microservice cho sản phẩm cần chạy ổn định và mở rộng.

Công nghệ mình dùng

  • TypeScript
  • React / Next.js
  • Node.js
  • PostgreSQL
  • Supabase
  • Docker
  • Microservice
  • Tailwind CSS
  • Browser extension (MV3)
  • Tích hợp LLM API

Cách làm việc

  1. Bạn kể bài toán. Việc gì đang tốn thời gian, làm tay thế nào.
  2. Mình làm một bản mẫu nhỏ trên đúng dữ liệu hoặc quy trình của bạn.
  3. Bạn dùng thử và kiểm tra xem có đúng thứ bạn cần không.
  4. Ưng mới tiếp tục. Phạm vi và giá thống nhất bằng văn bản trước khi làm phần lớn.
